# Sabor de Vó

Sistema web responsivo para gerenciamento de pedidos e controle de estoque de uma padaria fictícia.

## Objetivo
Facilitar a organização dos pedidos, acompanhar as movimentações de ingredientes e reduzir desperdícios.

## Tecnologias
- Python
- Flask
- HTML5
- CSS3
- SQLite

## Funcionalidades
- Cadastro e consulta de pedidos.
- Controle de estoque de ingredientes.
- Registro de entradas e saídas.
- Alertas de estoque mínimo.

Projeto acadêmico de Análise e Desenvolvimento de Sistemas.
